# 澜言 · 首次使用说明

> 一个原生 Android AI 聊天应用。装好之后，只要填对一个 API 地址和密钥就能开始聊。

---

## 一、安装

1. 把 `LanYan-x.x.x-debug.apk` 传到手机上，点击安装。
2. 如果系统提示"未知来源"，在弹窗里允许本次安装即可。
3. 打开 App，会先看到一个开屏动画，然后进入聊天页。

---

## 二、接入 API（最重要的一步）

澜言不自带模型，需要你自己的 API。以 **DeepSeek** 为例：

1. 浏览器打开 👉 <https://platform.deepseek.com/>
2. 注册 / 登录后，看**左侧菜单**，点击 **API Keys**
3. 点「创建 API Key」，复制生成的密钥（`sk-` 开头，只显示一次，记得保存）
4. 账户里需要有余额（按量计费，充一点就能用很久）

然后回到 App：

1. 左上角 **☰ 菜单** → 底部 **模型与偏好设置**
2. 找到「模型服务」：
   - **API 地址**：`https://api.deepseek.com/v1`（默认已填好）
   - **API 密钥**：粘贴刚才复制的 `sk-...`
   - **模型名称**：`deepseek-chat`（默认已填好）
3. 点 **测试连接**，看到「连接成功」就说明通了
4. 点 **保存设置**

> 地址末尾不用自己加 `/chat/completions`，App 会自动补全。

### 其他服务商

| 服务 | API 地址 | 模型名称示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| 通义千问（兼容模式） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 本地 Ollama | `http://电脑局域网IP:11434/v1` | 你本地安装的模型名 |
| 本地 LM Studio | `http://电脑局域网IP:1234/v1` | 你本地加载的模型名 |

- OpenAI 的密钥在 <https://platform.openai.com/api-keys> 获取
- 通义千问的密钥在阿里云百炼控制台获取
- **本地服务没有密钥时，API 密钥留空即可**
- 手机连本地服务时，不要填 `localhost`，要填电脑的局域网 IP（如 `192.168.1.10`），并确保手机和电脑在同一个 Wi-Fi 下

---

## 三、开始聊天

- **新对话**：点右上角 **＋**，或侧栏的「开启新对话」
- **发送**：输入框输入后点右下角 ↑
- **停止生成**：生成过程中点右下角的 ■
- **复制回答**：回答下方的复制图标
- **首页推荐问题**：会根据你最近的聊天自动生成，点「换一批」可以刷新

---

## 四、历史会话

- 点左上角 **☰** 打开侧栏
- 「搜索历史会话」可按标题查找
- 每个会话右侧 **⋮** 可以 **重命名** 或 **删除**
- 删除会话只删聊天记录，**长期记忆会保留**

---

## 五、长期记忆

开启后，澜言会记住你说过的重要信息，新对话里也能用上。

- 开关位置：设置 → Agent 长期记忆
- 让它记住，直接说：
  - 「请记住我喜欢简洁的回答」
  - 「我叫小林」
  - 「我正在开发一个记账 App」
- 查看 / 编辑 / 删除：侧栏 → **记忆中心**
- 自动整理会消耗少量 Token：每 12 条新消息合并一次会话摘要，并在你表达明确偏好时写入记忆

---

## 六、个性化

- **头像**：设置 → 个性化头像 → 更换 → 选图后可拖动、双指缩放、双击放大，裁成圆形头像
- **主题**：设置 → 外观 → 跟随系统 / 浅色 / 深色，立即生效
- **模型参数**：Temperature 越大回答越发散，最大输出 Token 控制单次回复长度，「近期消息数」控制带多少轮上下文

---

## 七、常见问题

| 现象 | 原因与解决 |
|---|---|
| 提示 401 / 403 | 密钥不对、过期或没有权限，重新复制一次 |
| 提示 404 | 模型名称写错，或 API 地址多了/少了路径 |
| 提示 402 / 余额不足 | 去服务商后台充值 |
| 连接超时 | 检查网络；国内访问 OpenAI 需要代理 |
| 本地服务连不上 | 用电脑局域网 IP，不要用 localhost；确认防火墙放行端口 |
| 回答被截断 | 调大「最大输出 Token」 |
| 想换服务商 | 改 API 地址、密钥、模型名三项，再测试连接 |

---

## 八、隐私

- API 密钥用 Android Keystore 加密，只存在本机
- 聊天记录、记忆都存在本机数据库，不上传任何服务器
- 只有发消息时，才会把对话内容发给你配置的模型服务商
